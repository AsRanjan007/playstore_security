## Public URL for Google Play

With GitHub Pages enabled (Settings > Pages > Deploy from a branch > `main`, folder `/ (root)`), the MusicVision
policy is served at:

https://asranjan007.github.io/playstore_security/musicvision/privacy-policy.html

Paste that URL into Play Console > Policy and programs > App content > Privacy policy.
